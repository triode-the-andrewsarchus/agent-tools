ConnectionManager

The ConnectionManager class coordinates asynchronous TCP and TLS connection pooling with exponential backoff retries.

Constructor Parameters

Parameter Type Default Description
host str Required The target server hostname or IPv4/IPv6 address.
port int 5432 Network port to connect to.
pool_size int 10 Maximum concurrent established connections in pool.
timeout float 30.0 Socket connection timeout in seconds.

Example Usage

Below is a minimal code example illustrating connection initialization:

import asyncio
from asyncdriver import ConnectionManager

async def main():
    pool = ConnectionManager(host="db.internal.net", port=5432, pool_size=20)
    await pool.connect()
    async with pool.acquire() as conn:
        result = await conn.query("SELECT id, name FROM users LIMIT 10;")
        for row in result:
            print(row)
    await pool.close()

if __name__ == "__main__":
    asyncio.run(main())

Error Handling

If a connection drops unexpectedly during a transaction, ConnectionResetError is raised. The pool automatically attempts to restore healthy connections according to the configured retry policy.
